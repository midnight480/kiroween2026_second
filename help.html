灯How to use the ledger帳面の使い方

Every task is a candle. Its length is the time left before the deadline. Finish it before it burns out.

ひとつの用事が、ひとつの蝋燭です。蝋燭の長さが、期限までの残り時間です。燃え尽きる前に片付けてください。

The board看板

  • To do, In progress and Done. Drag a card to another column, or use the ← → buttons on the card.
  • Open columns are sorted by deadline, nearest first. Done is sorted by when you finished.
  • A candle that burned out is marked 遅. It stays in its column until you deal with it.
  • 未着手、進行中、完了の3列です。カードを別の列へドラッグするか、カードの ← → ボタンで移します。
  • 未着手と進行中は、期限の近い順に並びます。完了は、終えた順に並びます。
  • 燃え尽きた灯には「遅」の印が付きます。片付けるまで、その列に残ります。

Projectsプロジェクト

  • The board shows one project at a time. Switch with the project name in the header, or P.
  • Project settings… renames the project and adds its own fields: text, number, choice, date, check or link. Mark a field Show on card to see it on the board.
  • To move a task to another project, open it with Rewrite and pick the project at the top.
  • Only a project with no open tasks can be deleted. Its finished tasks go with it.
  • 看板は1つのプロジェクトずつ表示します。ヘッダーのプロジェクト名か P で切り替えます。
  • プロジェクトの設定…で、名前を変え、そのプロジェクトだけの項目 (テキスト、数値、選択肢、日付、チェック、リンク) を足せます。カードに出すにした項目は、看板のカードに出ます。
  • タスクをほかのプロジェクトへ移すには、書き直すで開き、一番上のプロジェクトを選びます。
  • 消せるのは、未完了のタスクがないプロジェクトだけです。完了したタスクは一緒に消えます。

References参考資料

Paste links in the form under References. GitHub issues and pull requests show their number. Google Docs, Slides, Sheets and Drive, and Word, PowerPoint and Excel files on OneDrive or SharePoint are marked so you can tell them apart. Files are not uploaded: paste the file's link.

登録画面の参考資料にリンクを貼ります。GitHub の Issue と PR は番号が出ます。Google ドキュメント、スライド、スプレッドシート、ドライブ、OneDrive や SharePoint の Word、PowerPoint、Excel は、印で見分けられます。ファイルのアップロードはしません。ファイルのリンクを貼ってください。

Lighting a candle灯をともす

  • Press New candle (or N). Nothing is added until you press Light the candle.
  • Title and deadline are required. Assignee, status and notes are optional.
  • The deadline must be at least a minute away and within a year. Pick a time, or use a quick length (30 min, 2 hours, …).
  • Assignees are chosen from the team. Add a new name with + New member…, or on the Team page.
  • 新しい灯 (か N) を押します。灯をともすを押すまで、何も追加されません。
  • 件名と期限は必須です。担当者、状態、メモは任意です。
  • 期限は1分以上先、1年以内です。日時を選ぶか、長さ (30分、2時間 …) のボタンを使います。
  • 担当者は名簿から選びます。新しい名前は + 担当者を追加… か、名簿のページで足します。

The team名簿

  • Each project has its own roster. The Team page shows the roster of one project (pick it at the top): name, role, how many of that project's candles they carry, and when they were last seen.
  • A task can only be given to someone on its project's roster. Moving a task to another project keeps the assignee only if they are on that roster too.
  • Press This is me on your own row (once per project). From then on, this device records when you were last seen.
  • Last seen is only known for the person marked as you on each device, until sign-in is added.
  • Roles (Owner, Admin, Member, Viewer) are recorded now. They will limit what each person can do once sign-in is added.
  • Removing someone keeps their candles. They are left with nobody assigned.
  • 名簿はプロジェクトごとにあります。名簿のページは、上で選んだプロジェクトの名簿です。名前、役割、そのプロジェクトで担当している灯の数、最後に見た時が並びます。
  • タスクを任せられるのは、そのタスクのプロジェクトの名簿にいる人だけです。タスクをほかのプロジェクトへ移すと、移した先の名簿にいる場合だけ担当者が残ります。
  • 自分の行でこれが自分を押します (プロジェクトごとに1回)。以後、この端末で最後に見た時を記録します。
  • サインインを入れるまでは、各端末で「自分」の印を付けた人の時刻だけが分かります。
  • 役割 (オーナー、管理者、メンバー、閲覧者) はいまは記録だけです。サインインを入れたら、できることを役割で制限します。
  • 名簿から外しても、その人の灯は残ります。担当者なしになります。

APIAPI

Signed in, you can light and read candles from scripts and other tools. Keys are issued in your account (avatar → Manage account → API keys). How to use them is on the API docs page.

サインインすると、スクリプトやほかのツールから灯を登録・取得できます。キーはアカウントの画面で発行します (アバター → アカウントを管理 → API キー)。使い方は API ドキュメントのページにあります。

The candle and the clock蝋燭と時計

Sometimes a candle looks shorter than it should. The time written on the card is always the true time left. Trust the writing.

ときどき、蝋燭が本来より短く見えることがあります。カードに書かれた時間は、いつも本当の残り時間です。文字のほうを信じてください。

Safety安全のために

  • Safe mode removes flashes, the figure and the jump scare. It turns on by itself if your system asks for reduced motion.
  • Mute silences every sound.
  • Everything still works with both turned on.
  • セーフモードは、閃光、人影、驚かせる演出をなくします。端末で「視差効果を減らす」を設定していると、自動でオンになります。
  • 消音は、全ての音を止めます。
  • どちらをオンにしても、全ての機能を使えます。

Your dataデータ

Without signing in, tasks are saved in this browser only (localStorage) and are not sent anywhere. Clearing site data erases them. Signed in, your tasks and projects are kept in the ledger on the server, so you see them on every device. See the privacy policy.

サインインしない場合、タスクはこのブラウザの中 (localStorage) だけに保存され、どこにも送られません。サイトのデータを消すと、タスクも消えます。サインインすると、タスクとプロジェクトはサーバーの帳面に保存され、どの端末でも見られます。詳しくはプライバシーポリシーを見てください。
