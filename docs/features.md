# 基本機能 (タスク管理として担保する範囲)

提出物はタスク管理アプリです。演出の前に、タスク管理として普通に使えることを最低条件にします。

このファイルは機能の一覧と優先度です。各機能の振る舞い (状態、データ、操作、受け入れ基準) は `task-management.md` で定義しています。

## 合格ライン

- **Safe mode と Mute をオンにしても、全機能が使える。** 演出は機能の上に重ねるもので、機能の代わりにはしない。
- **ユーザーのデータを勝手に壊さない。** 演出で表示が揺れても、タイトル、期限、完了状態はユーザーが決めたとおりに保つ。
- **演出が操作を邪魔しない。** 入力中、ドラッグ中、封を剥がしている最中には、操作対象を動かさない。
- **怖さで意味を伝え、文字でも伝える。** 蝋燭の長さに加えて残り時間を文字で出す。色や動きだけで状態を伝えない。

## 多言語 (i18n)

- 対応言語は英語 (`en`) と日本語 (`ja`)。初期値は `navigator.language` から決め、フッターで切り替えられるようにする。選んだ言語は設定に保存する。
- 依存パッケージは使わず、キーと文言の辞書で持つ。`index.html` の文言も辞書から差し込む。`<html lang>` も切り替える。
- 和ホラーの語 (灯、遅、うしろ、遅かったね、数え歌) は、どの言語でも日本語のまま出す。英語版ではこの語だけが日本語なので、異物感が怖さになる。日本語版では、ほかの文言を静かな言い回しにして、これらの語を目立たせる。
- 日本語のほうが文字数が少なく、英語のほうが長い。御札の幅 (168px) に両方が収まるか確認する。
- 日付と残り時間の表示は `Intl` で言語に合わせる。

## ライト / ダーク

- 選択肢はライト、ダーク、システム設定に従う (`prefers-color-scheme`) の3つ。初期値はシステム設定に従う。選んだものは設定に保存する。
- 時刻によるテーマ変化 (逢魔が時、夜) は、ライトとダークのどちらにも色味として重ねる。ライト / ダークがベース、時刻はその上の味付け、という関係にする。
- どちらの表示でも、文字のコントラストは WCAG AA (本文 4.5:1) 以上にする。
- 期限切れの呪いの演出は、どちらの表示でも同じく暗転から始める。ライト表示からの暗転のほうが落差が大きい。

## 決定: 演出は実データを変えない (案A)

個別の返答はなく、「段階1〜5を一気に進める」との指示を受けて、推奨の案Aで実装しました。変えたい場合の差し替え箇所は `visualPct` (`src/store.ts`) と `shortenCandle` (`src/main.ts`) です。

- 「振り返るな」の罰 (見た目の残りの10%) と呪いの伝染 (25%) は、`Task.penalty` に「蝋燭が短く見える時間」として積む。実際の期限 `due` は変えない。
- 蝋燭の長さと炎の揺れは「見た目の残り」で決まり、文字の残り時間、期限の日時、赤字 (`urgent`) は「本当の残り」で決まる。
- 蝋燭が短いのに時計には余裕がある、というずれが怖さになる。
- 期限切れの判定は本当の期限だけで行う。

## 削除と完了 (決定)

| 操作 | 方法 | 見た目 | 記録 |
|---|---|---|---|
| 完了 | 封を長押し (0.9秒) か、Done の列へ移す | 蝋燭が消えて、Done の列へ移る | 「Put out」に数える |
| お祓い (遅れて完了) | 期限切れのカードの封を長押し | 同上。カードに「late」 | 「Put out」と `late` に数える |
| 削除 | 「Burn」を長押し (0.9秒) | 札が下から燃え、蝋燭が消える | 数えない |

どれも5秒間は元に戻せる。Done から未完了の列へ戻すと、完了の数から引く。
