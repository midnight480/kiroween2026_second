# コンセプト

## 目的

Kiroween 2026 の **Costume Contest** に提出する、不気味で洗練されたUIのWebアプリを作ります。

審査の趣旨 (原文):
> Build any app but show us a haunting user interface that's polished and unforgettable. Bring in spooky design elements that enhance your app's function.

評価されるのは次の3点です。
- UI自体が不気味であること
- 仕上がりが polished (洗練) であること
- 不気味な要素がアプリの機能を助けていること。「怖い見た目を貼り付けただけ」は評価されにくい

注記: Devpostのページは取得時に403で、要項の全文は未確認です。締切と提出要件は別途確認が必要です。

## アプリ

**灯 (Tomoshibi): The Candle Ledger**
タスクの期限を蝋燭の長さで表すToDoアプリです。蝋燭が燃え尽きる(期限切れ)と、何かが来ます。

## ユーザーの意向 (決定事項)
- 提出物はタスク管理アプリとして成立させる。基本機能を担保したうえで、見た目にこだわる (基本機能は `features.md`、見た目は `visual-design.md`)。
- 和ホラーの要素は、海外の審査員に意味が伝わる形で見せる。風習の意味は説明し、霊の正体は説明しない (`japanese-horror.md`)。

- 題材は「Haunted Todo」(案B)。
- 期限を蝋燭として表現する。
- 盤面でカードを動かすとガサガサと音がして、動かした課題が不気味に動く。看板の列の間をドラッグするときに鳴らす。
- 表示は状態別の看板 (カンバン) のみ。列は To do / In progress / Done。期限切れは列ではなく「遅」の印で示す。自由配置の盤面は廃止した。
- 登録は、件名を入れた瞬間に追加するのではなく、モーダルで件名、期限、担当者、状態、メモを入れてから確定する。
- 担当者は自由入力にせず、一覧から選ぶ。アカウントができるまでは端末内の一覧で代用する。
- ショートカットキーは別のヘルプページにまとめる。
- APIキーを発行し、APIでもタスクを登録できるようにする (認証の Clerk とあわせて後で実装する。`roadmap.md`)。
- 期限切れで、画面いっぱいに長髪の女性が「脅す」演出を入れる。参考は https://screenonline.jp/_ct/17578123 の雰囲気。画像は使わず独自に描く。
- 血糊を上から大量に流して画面が切り替わる演出を入れる。
- アメリカ的な不気味さは、UI部品のジャック・オー・ランタン程度にとどめる。
- 主役は日本的な恐怖。スプラッシュ的な視覚の恐怖ではなく、「何かそこにいるかも?」という想像を促すホラーにする。
- 「日常の小さな違和感」「破ってはいけないルール」「説明されない結末」を組み合わせる。
- 怖さが操作の分かりやすさ・楽しさに結びつく形にする。ジャンプスケアは控えめにし、可読性を保ち、演出はオフにできるようにする。

## 前提 (ユーザーが未回答だったため置いた仮定)

- UIは英語と日本語に対応し、ライトとダークの両方を用意する (決定)。和ホラーの語は、どちらの言語でも日本語のまま出す。
- 技術はVite + TypeScript。デプロイ先は Cloudflare (決定)。認証 (Clerk) と DB (Neon) を足すかは検討中 (`roadmap.md`)。
- Kiroのspec、steering、hooksを開発に使い、提出物に含めるかは未決定。
