# モバイル対応 (PWA とレスポンシブ)

スマートフォンでも、ホーム画面に置いたアプリとして使えるようにします。このファイルは、PWA の構成と、狭い画面での見え方の決まりをまとめます。

- 横幅が足りない端末があることを前提に作ります。新しい部品を足すときは、スマートフォン幅 (360px) での見え方を同じ変更で決めます。
- 音のモバイル固有の注意は `audio.md`、色と動きの決まりは `visual-design.md` にあります。

## PWA

### 目標

- ホーム画面に追加でき、ブラウザの枠なしの全画面 (`standalone`) で開く。
- 一度開けば、オフラインでも起動して使える。データは `localStorage` なので、オフラインでもタスク管理の全機能が使える。
- 起動からゲートまでの見た目を、作品の一部にする (墨色の地、灯のアイコン)。

### 構成 (依存パッケージなし)

`vite-plugin-pwa` を使うと楽ですが、依存の追加になるためユーザーの確認が必要です (`AGENTS.md`)。決まるまでは、手書きの manifest と Service Worker で作ります。

| ファイル | 置き場所 | 内容 |
|---|---|---|
| `manifest.webmanifest` | `public/` | 名前、アイコン、色、表示モード |
| `sw.js` | `public/` | オフライン用のキャッシュ。ルートに置き、スコープを `/` にする |
| アイコン | `public/icons/` | 192px、512px、maskable の 512px、`apple-touch-icon` の 180px。自作の SVG (闇に灯と「灯」の字) から書き出す。外部素材は使わない |
| 登録 | `src/main.ts` | `navigator.serviceWorker.register("/sw.js")`。開発中 (`import.meta.env.DEV`) は登録しない |
| `<head>` | `index.html` | manifest、`theme-color`、`apple-touch-icon`、`viewport-fit=cover` |

`manifest.webmanifest` の値:

```json
{
  "name": "Tomoshibi 灯 — The Candle Ledger",
  "short_name": "灯 Tomoshibi",
  "start_url": "/",
  "scope": "/",
  "display": "standalone",
  "orientation": "any",
  "background_color": "#0a0706",
  "theme_color": "#0a0706",
  "lang": "en",
  "icons": [
    { "src": "/icons/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/icons/icon-512.png", "sizes": "512x512", "type": "image/png" },
    { "src": "/icons/icon-maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ]
}
```

- `theme_color` はライト / ダークで変える。`<meta name="theme-color" media="(prefers-color-scheme: light)">` を2本置き、アプリ内でテーマを切り替えたら JS で書き換える。
- maskable アイコンは、灯を中央の円 (直径80%) に収める。端は切られる前提。

### Service Worker のキャッシュ方針

Vite のビルドはファイル名にハッシュが付くため、手書きの SW では一覧を固定できません。次の方針にします。

| 対象 | 方針 | 理由 |
|---|---|---|
| ページ (`/`、ナビゲーション) | ネットワーク優先。失敗したらキャッシュ | 更新をすぐ届けつつ、オフラインでも開ける |
| `/assets/*` (ハッシュ付きの JS、CSS) | キャッシュ優先。なければ取りに行って保存 | ハッシュが変われば別ファイルなので、古いものが出ない |
| アイコン、manifest | キャッシュ優先 | 変わらない |
| 他のオリジン (認証を入れた場合の Clerk、API) | キャッシュしない | 認証情報を保存しない |

- `install` で `/` と manifest、アイコンを入れる。`activate` で古いバージョンのキャッシュを消す。
- SW のキャッシュ名にバージョンを入れる (`tomoshibi-v1`)。中身を変えたら上げる。
- 新しい版が入ったら、次回起動で切り替える。使用中に勝手に再読み込みしない (呪いの演出中に再読み込みされると壊れるため)。

### 配信 (Cloudflare Workers)

- `sw.js` と `manifest.webmanifest` は長くキャッシュさせない。`public/_headers` で `Cache-Control: no-cache` を付ける。`/assets/*` は `max-age=31536000, immutable`。
- HTTPS 必須 (Workers は標準で HTTPS)。`localhost` は開発でも SW が動く。
- 静的アセットの設定で、存在しないパスを `index.html` に返す設定にするかは、神隠しの404ページ (`roadmap.md`) と合わせて決める。

### インストールの案内

- Android の Chrome は `beforeinstallprompt` を受け取れる。イベントを保存しておき、フッター (狭い画面ではメニューの中) に「Keep the candle (Install)」を出す。勝手に出さない。
- iOS Safari にはイベントがない。共有メニューから「ホーム画面に追加」する方法を、メニューの中に1行で書く。
- `display-mode: standalone` で開いているときは、案内を出さない。

### 端末を閉じている間の期限

PWA でも、アプリを閉じている間は JS が動きません。期限切れの判定は、次に開いたときにまとめて行われます。

- **要判断**: 閉じている間に複数件が期限切れになっていたら、呪いを何回流すか。推奨は「呪いの演出は1回だけ流し、残りは『遅』の印を付けるだけ」。1タスク1回の決まり (`ui-mapping.md`) は守りつつ、開いた瞬間に何分も演出が続くのを避けます。
- 閉じている間に期限を知らせるには Web Push (サーバーが必要) か、未普及の通知予約 API が要ります。バックエンドを持たない現状では対象外とし、`features.md` の「期限前のブラウザ通知」(Could) で扱います。

## レスポンシブ

### 画面幅の区分

| 区分 | 幅 | 想定 | ヘッダー | フッターの設定類 | 盤面 |
|---|---|---|---|---|---|
| 広い | 1024px 以上 | PC | 1行。ブランド + New candle | フッターに並べる | 看板の3列 |
| 中 | 720〜1023px | タブレット、狭いウィンドウ | 1行 | フッターに並べる | 看板の3列 |
| 狭い | 720px 未満 | スマートフォン | 2段。上段にブランドとメニューボタン、下段に追加フォーム | メニューの中に収める | 縦に並べる (下記) |
| とても狭い | 360px 未満 | 小さい端末、横分割の画面 | 狭いと同じ。選択肢の文言を短くする (`2 hours`) | メニューの中 | 1列 |

- いまの CSS の区切りは 720px だけです。上の区分に合わせて足します。
- 区切りは端末名ではなく、部品が収まらなくなる幅で決めます。英語の文言は日本語より長いので、英語で確かめます。
- 横向きのスマートフォン (高さ 360px 前後) では、ヘッダーとフッターで高さを取りすぎないよう、ヘッダーを1段に戻します (`@media (max-height: 480px)`)。

### メニュー (ハンバーガー)

狭い画面では、フッターの設定類をメニューにまとめます。メニューは、ロードマップの「襖のモーダル」(`roadmap.md`) と同じものにします。

| 項目 | 決まり |
|---|---|
| 入れるもの | Safe mode、Mute、言語、テーマ (ライト / ダーク / システム)、家の掟、インストールの案内 |
| 外に残すもの | 追加フォーム、呪われた数のカウンタ。毎回使うものと、状態を示すものはメニューに隠さない |
| ボタンの形 | 三本線 (☰) のまま、筆で引いた墨の線にする。形を変えると、メニューだと分からなくなる (機能が先) |
| ボタンの位置 | 右上。親指が届きにくいが、慣習に合わせる |
| 開き方 | 襖が横からすっと開く (怪異の動きではなく操作の反応なので 0.2〜0.3秒)。reduced-motion と Safe mode ではフェードだけ |
| 閉じ方 | 閉じるボタン、背景を押す、Esc、戻る操作 |
| アクセシビリティ | `<button aria-expanded aria-controls>`。開いている間は背景を `inert` にし、フォーカスをメニューの中に閉じ込める。閉じたらボタンにフォーカスを戻す |
| 気配との関係 | メニューを開いている間は、気配の演出と期限切れの判定を止める (入力中と同じく、操作対象を動かさない)。期限切れはメニューを閉じた後に流す |

### 看板 (狭い画面)

自由配置は廃止し、全ての幅で看板にしました (`concept.md`)。

- 720px 未満では、3つの列を横に並べ、1列ずつ横スワイプで見る (`scroll-snap`)。列の幅は画面の88%で、隣の列の端が見えるので、横に続きがあると分かる。
- カードの移動は、カードの ← → ボタンを使う。ドラッグは 6px 動かしたときだけ始まるので、タップとは区別される。
- 「New candle」ボタンは南瓜だけになる。登録モーダルは画面の幅に合わせ、担当者と状態は縦に並ぶ。

### タッチ操作

マウス前提の演出は、タッチでの代わりを決めます。

| 演出・操作 | マウス | タッチでの代わり |
|---|---|---|
| 灯 (カーソルの周りだけ明るい `#dark`) | カーソルを追う | 最後に触れた位置を追う。触れていない間は、最も急ぎの蝋燭の周りを照らす |
| 見るなのタブー (人影に近づくと罰) | カーソルが近づく | 人影の近くに触れる。スクロール中の指は数えない |
| 御札の封の長押し (0.9秒) | 押し続ける | 同じ。長押しで出る文字選択と、iOS のメニューを止める (`-webkit-touch-callout: none`、`contextmenu` を `preventDefault`) |
| ホバーで光る南瓜、ボタン | ホバー | `@media (hover: hover)` のときだけホバーの演出を付ける。タッチでは押した瞬間 (`:active`) に光る |
| title 属性の説明 | ホバーで出る | タッチでは出ない。必要な説明はメニューか本文に書く |

### 寸法の決まり

- 押せるものは 44×44px 以上。チェックボックスはラベルごと押せるようにする。
- 入力欄の文字は 16px 以上。iOS は16px未満の入力欄に触れると画面を拡大する。
- 画面の高さは `100vh` ではなく `100dvh` を使う。アドレスバーの出入りでずれないようにする。
- `viewport-fit=cover` にし、ノッチとホームバーの分を `env(safe-area-inset-*)` で空ける。ヘッダー、フッター、メニュー、呪いの画面に適用する。
- 横スクロールを出さない。`overflow-x: hidden` で隠すのではなく、はみ出す部品を直す。
- 呪いの Canvas は `devicePixelRatio` に合わせて描き、縦長の画面でも女が画面に収まるようにする。

### 確認する幅

提出前に、少なくとも次の幅で確かめます (`visual-design.md` の確認項目)。Chrome の DevTools のデバイス表示に加え、実機で1回は確かめます。

| 幅×高さ | 想定 |
|---|---|
| 320×568 | 小さい iPhone。最も厳しい幅 |
| 360×800 | Android の標準的な幅 |
| 390×844 | 標準的な iPhone |
| 844×390 | スマートフォンの横向き |
| 768×1024 | タブレットの縦向き |
| 1366×768 | 小さいノートPC |

確認すること:

- ヘッダー、カード、メニューの文字が切れず、横スクロールが出ない (英語と日本語の両方)。
- メニューを開いて Safe mode と Mute を切り替えられ、Esc と戻る操作で閉じる。
- ホーム画面から開いて、オフラインでも起動し、タスクを追加できる。
- 裏に回して戻したあと、音と期限の判定が再開する (`audio.md`)。
