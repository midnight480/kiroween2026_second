# デザイン原則

日本のホラーの怖さは、派手な怪物より、静けさ、湿度、日常のズレ、因習から生まれます。

美意識の基調は、谷崎潤一郎『陰翳礼讃』の「陰の中の美」と、「間」と「気配」です。各概念の意味と英語での伝え方は `japanese-horror.md`、色・文字・動きの決まりは `visual-design.md` にあります。
## 3つの柱

1. **日常の中の小さな違和感**: カードがわずかにずれる、タイトルが一瞬「うしろ」になる。
2. **破ってはいけないルール**: 「振り返るな」「蝋燭を死なせるな」。破ると罰がある。
3. **説明されない結末**: 女は誰か、なぜ来たかを語らない。

## 演出のルール

- 静寂と間を使う。音を消し、何も起きない時間を長く取る。
- はっきり見せない。人影は画面の端、顔は髪の隙間から片目だけ。
- 近づくと消える。見ようとした代償として罰が起きる。
- 演出は頻度を抑える。通常時は20〜55秒に1回、蝋燭が残り25%を切ると7〜16秒に1回。
- 強い演出 (閃光、大音量、全画面の女) は期限切れの1回だけ。
- 血、御札、赤い紐、和紙、墨の質感でUIを統一する。

## 機能との関係
- 演出は機能の上に重ねる。Safe mode と Mute でも、タスク管理の全機能が使える (`features.md`)。
- 演出でユーザーのデータを壊さない。罰や伝染が実際の期限を変えてよいかは要判断 (`features.md`)。
- 怪異の動きは「ゆっくり」か「唐突」にし、操作の反応 (すぐ) と見分けられるようにする。
## 時間帯

- 丑三つ時 (02:00〜03:00): 気配の頻度を上げる。
- 逢魔が時 (17:00〜18:00): 暗さと色味が不穏なテーマに切り替わる。
- 夜 (19:00〜05:00): 最も暗い。昼間も本文が読める暗さに抑える。

## 可読性と安全面

- 本文、ボタン、期限の表示ははっきり読める濃さにする。かすれ文字は見出しと装飾だけ。
- 周辺光 (カーソル追従の暗闇) は、端でも読める濃さにする。
- **Safe mode**: 閃光、人影、女の登場、ジャンプスケアをなくす。血と文字は残す。
- **Mute**: 全音声を止める。
- `prefers-reduced-motion: reduce` のとき、Safe mode を自動でオンにする。
- ゲート画面で、突然の映像、血、大きな音を含むことを事前に警告する。

## 和ホラー要素のメモ (参照用。採用したものの意味は `japanese-horror.md`)

| 分類 | 要素 |
|---|---|
| 怪異 | 長い黒髪の女の霊、座敷わらし、のっぺらぼう、神隠し、八尺様、きさらぎ駅 |
| 場所 | 廃校、トンネル、田舎の集落、団地、祠 |
| 小道具 | 御札、盛り塩、日本人形、井戸、鏡、押し入れ、襖の隙間、赤い紐、鳥居、注連縄、ビデオテープ |
| ルール | 呪いの伝染、「やってはいけない」、数え歌、静寂と間、因果応報、正体を見せない |
| 時間 | お盆、丑三つ時、逢魔が時、梅雨と夏の夜 |
