# ビジュアルデザイン

審査で最も見られるのは見た目の仕上がりです。このファイルは、色、文字、質感、動きの決まりと、仕上げの確認項目をまとめます。値は `src/style.css` の現状に合わせています。

## 基調: 陰翳礼讃

画面は「蝋燭一本で照らした和室」です。大半は陰で、灯の周りだけが見えます。光は飾りではなく、「いま見るべき所」を示す情報として使います。

- 背景は墨色の闇。和紙と蝋だけが光を受けて浮かぶ。
- 光源は炎とカーソルの灯の2つ。それ以外のものは自分から光らない (ジャック・オー・ランタンだけ例外)。
- 暗くしてよいのは背景と装飾まで。本文、期限、ボタンは読める濃さを保つ (`design-principles.md`)。

## ライトとダーク

どちらも「同じ部屋の、時間が違う姿」として作ります。ライトは単に色を反転したものではありません。

| | ダーク: 夜の和室 | ライト: 白昼の障子 |
|---|---|---|
| 着想 | 陰翳礼讃。蝋燭一本の部屋 | 夏の昼、障子越しの白い光。明るいのに誰もいない静けさ |
| 地 | 墨の闇。襖の柱が縦に並ぶ | 障子の白と格子。色褪せた紙 |
| 光と影 | カーソルの周りだけ明るい | 明るい画面に、カーソルの周りだけ影が落ちる (誰かが後ろに立っている) |
| 気配の出方 | 闇の中の目、端の人影 | 障子に映る人影 (影絵)。紙の向こうを誰かが横切る |
| 御札 | 闇に浮かぶ黄ばんだ和紙 | 白い地に置かれた古い和紙。朱がより目立つ |
| 炎 | 唯一の光源 | 昼でも灯っている、という違和感 |

昼の怖さは日本のホラーで定番です (八尺様、真夏の田舎や団地)。ライトにしても怖さは抜けない、というのを狙いにします。

## 色

以下はダークの値です。ライトの値は実装時にこの表へ列を足します。

| 名前 | 値 | 使う所 | 決まり |
|---|---|---|---|
| 墨 (背景) | `#0a0706` | 画面の地 | 真っ黒 (`#000`) は呪いの暗転にだけ使う |
| 和紙 | `--paper` `#d8cdb0` | 御札、ゲートの文字 | 白 (`#fff`) は使わない。紙は古く黄ばんでいる |
| 墨文字 | `--ink` `#1a1410` | 御札の文字 | |
| 本文 (暗い地の上) | `#cbbfa6` | ヘッダー、フッター、案内文 | |
| 朱 | `#8e1010` | 赤い紐、「遅」の印、タイトル改変 | 印と罰だけに使う。ボタンの色にはしない |
| 血 | `--blood` `#7a0a0a` | 呪いの血、エラー枠 | 期限切れとエラーだけ |
| 灯 | `--flame` `#ffb347` | 炎、ブランドの「灯」、ボタンのホバー | 灯が当たる所 = 操作できる所 |
| 南瓜 | `#e8730c` 系 | ジャック・オー・ランタンだけ | 他の部品に広げない |

整理が必要な点: 朱は `#8e1010` と `#8a1010`、血は `#7a0a0a` と近い値が混ざっています。CSS変数 (`--shu`、`--blood`) にまとめます。

## 文字

- 書体は明朝体 (`Hiragino Mincho ProN`, `Noto Serif JP`, `Yu Mincho`, 最後は `Georgia`)。筆で書いた札の雰囲気に寄せる。
- 日本語 (灯、遅、うしろ、遅かったね、数え歌) は、見出しと印と演出だけに使う。操作の説明は英語で書く。
- 本文は12px以上。字間を広げてよいのは見出しとラベルまで。
- 未決定: Windows と Android には明朝体が入っていないことが多く、`Georgia` に落ちて印象が変わります。フォントを同梱するかは「外部素材を使わない」方針との兼ね合いで、ユーザーに確認が必要です (`roadmap.md`)。

## 質感

| 質感 | 表し方 | 使う所 |
|---|---|---|
| 和紙 | 横の細い筋 (repeating-linear-gradient) と、内側の影 | 御札 |
| 蝋 | 左右の陰影、上面の楕円、垂れた蝋 | 蝋燭 |
| 赤い紐 | 御札の上から垂れる細い朱の線 | 御札 |
| 印 (判子) | 傾いた朱の一文字 | 呪われたカードの「遅」 |
| 襖・柱 | 背景の縦の繰り返し | 盤面の地 |
| 墨のにじみ | 未実装 | 画面遷移の候補 |

## 動き

動きは2種類だけにします。「何かが動いた」と「自分が動かした」を見分けやすくするためです。

| 種類 | 速さ | 例 | 意味 |
|---|---|---|---|
| 操作の反応 | すぐ (0.1〜0.3秒) | ボタンのホバー、ドラッグ、封の剥がれ始め | 自分がやったこと |
| 怪異の動き | ゆっくり (1〜2.5秒) か、唐突 (`steps`) | カードがすっと滑る、人影がにじみ出る、カードが震える | 自分以外の何かがやったこと |

- 「ふつうのUIアニメ」(0.3〜0.6秒の ease) は怪異に使わない。中途半端な速さは怖くない。
- 何も動かない時間を長く取る (`design-principles.md` の間)。
- `prefers-reduced-motion` では Safe mode を自動でオンにし、炎のちらつきと震えを止める。

## 部品ごとの表現

| 部品 | 機能 | 表現 | 仕上げの課題 |
|---|---|---|---|
| ゲート | 警告と入場 | 闇に浮かぶ「灯」。蝋燭を灯して入る | 入場時に灯がともる一瞬が欲しい |
| ヘッダー | タスク追加 | 闇の上端。南瓜が入力を受けて光る | 720px 未満で2段にする (`mobile.md`) |
| カード | タスク1件 | 左に蝋燭、右に横長の御札 + 赤い紐 | |
| 封 | 完了の確認 | 長押しで剥がれていく | 剥がれる進み具合が目で分かるか確認 |
| 盛り塩 | 入力エラー | 塩の山が崩れる | |
| 座敷わらし | 空の状態 | 部屋の真ん中に子どもが一人 | |
| フッター | 設定と状態 | 「家の掟」と、呪われた数 | 720px 未満では設定類を襖のメニューに収める (`mobile.md`) |
| 呪いの画面 | 期限切れの通知 | 暗転 → 血 → 女 → 「遅かったね」 | 女の描画の質 (`roadmap.md`) |

## 仕上げの確認項目

提出前に、通常、Safe mode、夜のテーマの3つで確認します。

- [ ] 本文、残り時間、ボタンが、暗闇の端でも読める
- [ ] 1366×768、1920×1080、スマートフォン幅 (320〜390px、横向き) でレイアウトが崩れず、横スクロールが出ない (`mobile.md`)
- [ ] 狭い画面でメニューが開閉でき、設定に届く
- [x] カードが10件あっても重ならず、全部見える (看板にしたため)
- [ ] 色が上の表から外れていない (朱と灯の使い分け)
- [ ] 怪異の動きと操作の反応を見分けられる
- [ ] 明朝体がない環境で見た目を確認した
- [ ] フォーカスリングが見える (キーボード操作)
- [ ] 呪いの演出が、通常と Safe mode の両方で最後まで破綻しない
