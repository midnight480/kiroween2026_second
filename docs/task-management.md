# タスク管理の機能仕様

灯はタスク管理アプリです。このファイルは、演出を全部外したときに残る「タスク管理としての振る舞い」を定義します。演出はこの仕様の上に重ねます (`AGENTS.md` 方針0)。

- 機能の一覧、優先度、実装状況は `features.md` にあります。このファイルは「各機能が正確にどう振る舞うか」を決めます。
- 演出との対応は `ui-mapping.md`、データの保存の仕組みは `architecture.md` にあります。
- 「要判断」の点は、推奨案で仕様を書いています。ユーザーが別の案を選んだら書き直します。

## どんなタスク管理か

| 項目 | 決まり |
|---|---|
| 使う人 | 個人。1人で、1台の端末 (ブラウザ) で使う |
| 扱うタスク | 数分〜数日のうちに終える用事。**全てのタスクに期限がある** (期限 = 蝋燭の長さ) |
| 優先度 | 期限で表す。優先度の項目は持たない。急ぐものほど蝋燭が短い |
| 件数 | 同時に灯っているのは数件〜30件程度を想定。上限は60件 |
| 対象外 | チームでの共有、プロジェクトの階層、サブタスク、タグ、カレンダー表示。理由: 「蝋燭が燃え尽きる前に片付ける」という1つの体験に絞るため |
| 対象外 (候補) | 繰り返しのタスク、期限のないタスク。入れる場合は `features.md` に行を足して決める |

## 用語

| 用語 | 意味 | 画面での呼び名 (英 / 日) |
|---|---|---|
| タスク | やること1件。御札のカード1枚 | candle / 灯 |
| 期限 (`due`) | タスクを終えるべき日時。ユーザーが決める | — |
| 燃焼時間 | 追加した時刻から期限までの長さ。蝋燭の全長 | burns for / 燃える時間 |
| 残り時間 | いまから期限までの長さ。蝋燭の残りの長さ | — |
| 完了 | タスクを終えたこと。封を剥がして灯を消す | peel the seal / 封を剥がす |
| 期限切れ | 完了しないまま期限を過ぎたこと。蝋燭が燃え尽きる | extinguished / 遅 |
| 削除 | 間違えて作った、不要になったタスクを消すこと。完了とは別 | burn the ofuda / 札を焼く |
| 記録 | 完了したタスクの履歴 | ledger / 帳 |

## タスクの状態

```
            追加
             │
             ▼
   ┌──── 灯っている (active) ────┐
   │         │    ▲              │
   │ 完了    │    │ 延長          │ 削除
   │         ▼    │              ▼
   │      期限切れ (expired) ── 削除 ──▶ (消える。5秒間は元に戻せる)
   │         │
   │         │ 遅れて完了
   ▼         ▼
  完了 (done) ──▶ 記録に残る。5秒間は元に戻せる
```

| 状態 | 意味 | 盤面 | できる操作 |
|---|---|---|---|
| 灯っている | 期限前で、未完了 | 出る。蝋燭が燃えている | 完了、編集、延長、削除、移動 |
| 期限切れ | 期限を過ぎて、未完了 | 出る。「遅」の印と取り消し線 | 遅れて完了、延長、削除、移動 |
| 完了 | 終えた | 出ない。記録に出る | 元に戻す (5秒以内)、記録からの削除 |

- **期限切れは「終わり」ではない。** タスク管理として、期限を過ぎてもやることは残っています。期限切れのタスクも、遅れて完了したり、期限を延ばしたりできるようにします。
- いまの実装では、期限切れのタスクは「exorcise (お祓い)」で消すしかなく、中身は削除です。これを「遅れて完了」と「削除」の2つに分けます。お祓いの名前は、遅れて完了のほうに使います (呪いを祓って、帳に記す)。
- 呪いの演出は、1タスクにつき最初の期限切れの1回だけです。延長したタスクがまた期限切れになっても、演出は流さず「遅」の印だけを付けます。

## データ

いまの `Task` (v1) に、状態と記録のための項目を足します (v2)。

```ts
interface Task {
  id: string;            // crypto.randomUUID()
  title: string;         // 1〜40文字。前後の空白は除く
  note?: string;         // 補足 (Could)。0〜200文字
  created: number;       // 追加した時刻 (ms)。蝋燭の全長の起点。延長しても変えない
  due: number;           // ユーザーが決めた期限 (ms)。演出では変えない (下の「期限の正しさ」)
  status: "active" | "expired" | "done";
  doneAt?: number;       // 完了した時刻。status が done のとき
  late?: boolean;        // 期限を過ぎてから完了したか
  extended: number;      // 延長した回数
  cursed: boolean;       // 呪いの演出を再生済みか。status とは別に持つ
  x: number; y: number;  // 盤面上の位置 (px)。狭い画面では使わない (mobile.md)
  updated: number;       // 最後に変更した時刻 (ms)。複数タブの同期に使う
}
```

- 保存キーは `tomoshibi.tasks.v2`。初回の読み込みで v1 から移す: `cursed: true` は `status: "expired"`、それ以外は `"active"`。移したあとも v1 のキーは消さずに残す (戻せるように)。
- 完了したタスクは同じ配列に `status: "done"` で残す。記録は直近の200件まで残し、それより古いものは消す。
- 期限切れの判定は「`status` が `active` で `due <= now`」。判定したら `status` を `expired` にして保存する。

## 機能ごとの仕様

### 追加

| 項目 | 決まり |
|---|---|
| 入力 | タイトル (必須) と期限。期限はプリセット (1分 デモ、30分、2時間、1日、3日) か、日時の指定 |
| タイトル | 前後の空白を除いて1〜40文字。改行は入れられない |
| 期限の指定 | いまより1分以上先、1年以内。範囲外は盛り塩のエラー |
| 確定 | Enter キー、または南瓜のボタン |
| 確定後 | 入力欄を空にし、フォーカスをタイトルの入力欄に戻す (続けて追加できる)。期限の選択は前回のまま |
| 置き場所 | 空いている場所に置く。既存のカードと重ならない (`features.md` の一覧性) |
| 上限 | 灯っている + 期限切れで60件。超えたら追加せず、理由を出す |

### 表示

各カードに、次を必ず文字で出します。色や蝋燭の長さだけで伝えません。

| 表示 | 例 | 決まり |
|---|---|---|
| タイトル | `Submit the report` | 全文。御札の幅で折り返す |
| 残り時間 | `2h 14m` | 1秒ごとに更新。残り20%未満は強調色 |
| 期限の日時 | `Tue 18:00` / `11月18日(火) 18:00` | **いまは出ていない。足す。** 今日なら時刻だけ、7日以内なら曜日と時刻、それより先は日付と時刻。`Intl.DateTimeFormat` で言語に合わせる |
| 状態 | `extinguished` + 「遅」 | 期限切れは、印と文字の両方で示す |

盤面の上か下に、件数を文字で出します: 灯っている数、期限切れの数 (いまの Haunted カウンタ)、今日完了した数。

### 並べ方

| 画面 | 並べ方 |
|---|---|
| 広い画面 | 自由配置。ドラッグで置いた位置を保存する |
| 狭い画面 (720px 未満) | 期限の近い順に縦に並べる (`mobile.md` の要判断。推奨案) |
| 整列 (Should) | 広い画面でも「期限順に並べ直す」ボタンで、期限の近い順に左上から並べ直せる。散らかった盤面を一度で直す |

### 完了

| 項目 | 決まり |
|---|---|
| 操作 | 封を0.9秒長押し (マウス、タッチ)。キーボードは封にフォーカスして Space か Enter を0.9秒押し続ける |
| 途中でやめる | 0.9秒より前に離せば何も起きない。誤操作の防止を兼ねる |
| 結果 | `status: "done"`、`doneAt` を記録。期限前なら `late: false` |
| 元に戻す | 画面の下に「灯を戻す (Undo)」を5秒出す。押すと完了前の状態に戻る |
| 遅れて完了 | 期限切れのタスクも同じ操作で完了できる。ラベルは「Hold to exorcise」。`late: true` |

### 削除

完了と削除は、結果が違うので操作を分けます。

| 項目 | 決まり |
|---|---|
| 操作 | カードのメニュー (… のボタン) から「札を焼く (Burn)」を選び、長押しで確定 |
| 結果 | タスクを消す。記録には残らない |
| 元に戻す | 5秒間「元に戻す (Undo)」を出す |
| 演出 | 完了は灯が消えて札が残る、削除は札ごと燃える。見た目で違いが分かる (`ui-mapping.md`) |

### 編集 (Should)

| 項目 | 決まり |
|---|---|
| 操作 | カードのタイトルを押す (キーボードは Enter) と、その場で入力欄になる。期限はカードのメニューから |
| タイトル | 追加と同じ制限 |
| 期限 | 追加と同じ制限。`created` は変えない。期限切れのタスクの期限を未来にしたら、灯っている状態に戻る (延長と同じ) |
| 確定とキャンセル | Enter か入力欄の外を押して確定。Esc でキャンセル |
| 演出を止める | 編集中は、そのカードを気配の演出で動かさない |

### 延長 (Should)

| 項目 | 決まり |
|---|---|
| 操作 | カードのメニューから「蝋燭を継ぐ (Extend)」で +30分、+2時間、+1日、日時の指定 |
| 起点 | 灯っているタスクは、いまの期限から延ばす。期限切れのタスクは、いまから延ばす |
| 結果 | `due` を更新し、`extended` を1増やす。期限切れなら `status: "active"` に戻す。`cursed` はそのまま (呪いは2度来ない) |
| 表示 | 継ぎ足した蝋燭は、継ぎ目の線が見える。延長した回数が見て分かる |

### 記録 (Should)

| 項目 | 決まり |
|---|---|
| 場所 | メニューの「帳 (Ledger)」。狭い画面ではハンバーガーメニューの中 |
| 中身 | 完了したタスクを新しい順に。タイトル、完了日時、期限内か遅れたか |
| 集計 | 今日、今週に完了した数。期限内に終えた割合 |
| 操作 | 1件ずつの削除、全消去 (確認あり) |
| 百物語 (提案) | 採用したら、消した灯の総数を `37 / 100` のように数える (`japanese-horror.md`) |

### 期限の知らせ

アプリを開いている間は、段階的に知らせます。どれも文字でも出します。

| 残り | 知らせ方 | Mute / Safe mode でも分かる表示 |
|---|---|---|
| 25%未満 | 気配が増える | 残り時間が強調色になる (20%未満) |
| 60秒 | 遠い歌声「くる」(`audio.md`) | 蝋燭のそばに「くる」 |
| 10秒 | 数え歌 | 「ひとつ、ふたつ…」の文字 |
| 0秒 | 呪い (1タスク1回) | 「遅」の印と `extinguished` |

- タブが裏にあるとき (Could): 許可を得たうえで、ブラウザの通知 (`Notification`) を期限の5分前と期限切れに出す。許可はユーザーが設定から求めたときだけ聞く。初回の起動では聞かない。
- アプリを閉じている間は知らせない (サーバーがないため。`mobile.md`)。次に開いたとき、期限切れをまとめて表示する。

### 保存

| 項目 | 決まり |
|---|---|
| 保存先 | `localStorage`。変更のたびにすぐ保存する |
| 壊れたデータ | 読み込みで JSON の解析に失敗したら、**元の文字列を `tomoshibi.tasks.broken.<時刻>` に退避してから**空で始め、画面に知らせる。いまの実装は空の配列を返し、次の保存で元のデータを上書きしてしまう (`roadmap.md`) |
| 保存の失敗 | 容量超過などで `setItem` が失敗したら、操作を取り消さずに画面で知らせる |
| 複数のタブ | `storage` イベントで他のタブの変更を受け取り、盤面を更新する。同じタスクを両方で変えたら `updated` が新しいほうを採る。呪いの演出は1つのタブでだけ流す |
| 書き出しと読み込み (Should) | 設定から JSON で書き出し、読み込める。端末の移行とバックアップ用。読み込みは「置き換える」と「足す」を選べる |
| 認証を入れた場合 | 端末間で同期する。仕様は `roadmap.md` の「検討中: 認証」 |

### 期限の正しさ

**要判断** (`features.md`)。推奨案Aで書きます。

- `due` はユーザーが決めた期限で、演出では変えない。残り時間の文字と期限の日時は、常に `due` から出す。
- 「振り返るな」の罰と呪いの伝染は、蝋燭の**見た目の長さだけ**を縮める。見た目の縮み分は `Task` とは別の表示用の値として持ち、保存しない (再読み込みで戻る) か、保存しても期限の計算には使わない。
- 蝋燭は「霊から見た残り時間」、文字は「本当の残り時間」。ずれ自体を怖さとして見せる。

### 時刻の扱い

- 期限は UTC のミリ秒で保存し、表示は端末のタイムゾーンで出す。
- スリープや裏に回って戻ったときは、戻った時点で期限切れの判定をやり直す。
- 端末の時計が大きく戻った場合 (追加時刻より前) は、残り時間を燃焼時間で頭打ちにし、蝋燭が全長を超えないようにする。

## キーボード操作

| キー | 場所 | 動き |
|---|---|---|
| `N` か `/` | どこでも (入力中を除く) | タイトルの入力欄にフォーカス |
| Enter | タイトルの入力欄 | 追加 |
| Tab | 盤面 | カードを期限の近い順に移動 (見た目の位置ではなく) |
| Space / Enter (長押し) | 封 | 完了 |
| Enter | カードのタイトル | 編集 (Should) |
| 矢印 | カード | 盤面上で10pxずつ移動。Shift で50px (Should) |
| Esc | 編集中、メニュー | キャンセル、閉じる |
| `Ctrl/Cmd + Z` | どこでも (入力中を除く) | 直前の完了・削除を元に戻す (5秒以内) |

## 実装との差分 (段階1〜5の時点)

この仕様のうち、次は仕様どおりではなく、簡略化して実装しています。

| 項目 | 仕様 | 実装 | 理由・次の手 |
|---|---|---|---|
| データ形式 | v2 (`status`、`doneAt`、`late`、`extended`、`updated`)。完了も同じ配列に残す | v1 のまま (`penalty` だけ足した)。状態は `due` と `cursed` から導く (`due <= now` なら期限切れ)。完了したタスクは残さず、`tomoshibi.stats` に件数だけ持つ | 記録の一覧画面と複数タブの同期を作るときに v2 へ移す |
| 削除の操作 | カードのメニュー (…) から「札を焼く」を長押し | カード上の「Burn」ボタンを長押し | メニューは `mobile.md` の襖のメニューと一緒に作る |
| 元に戻す | 完了と削除を5秒以内 | 直前の1件だけ。次の操作で前の1件は確定する | 複数件は記録 (v2) と一緒に |
| 延長 | +30分、+2時間、+1日、日時の指定。起点は期限切れならいまから。`created` は変えない | 日時の指定なし。期限切れの延長は `created` もいまに置き直す (新しい蝋燭として長さを測り直す。そうしないと、延ばした直後の蝋燭がほぼ消えて見える) | 日時の指定は編集の期限変更と一緒に |
| 期限の編集 | カードのメニューから | 延長だけ | |
| 期限の範囲 | 1分以上先、1年以内 | 同じ (カスタム日時のみ検証。プリセットは範囲内) | |
| 上限 | 60件 | 同じ | |
| 件数の表示 | 灯っている数、期限切れの数、今日完了した数 | 期限切れの数 (Haunted) と、消した灯の総数 (Put out) | 「今日完了」は記録 (v2) と一緒に |
| 気配を止める | 編集中、メニュー表示中 | 編集中のカードだけ止める | メニューは未実装 |
| 呪いの再生 | 1タスクにつき最初の1回だけ | 同じ。延長して再び期限切れになっても、「遅」の印だけが付く | |
| 未実装 | 複数タブの同期、書き出し・読み込み、期限順の整列、期限順の Tab、期限の5分前の通知、補足メモ、時計が戻ったときの頭打ち | 未実装 | `features.md` の Should / Could |

## 受け入れ基準

Safe mode と Mute をオンにした状態で、全て満たすこと。

- [x] タイトルと期限を入れて追加でき、再読み込みしても残る
- [x] 空のタイトル、過去の日時、1年より先の日時は追加されず、理由が文字で出る
- [x] 各カードで、タイトル、残り時間、期限の日時、状態が文字で読める
- [x] 10件追加しても、カードが重ならない
- [x] 完了と削除が別の操作で、どちらも5秒以内なら元に戻せる
- [x] 期限切れのタスクを、遅れて完了、延長、削除のどれでも処理できる
- [x] 演出が起きても、`due` と残り時間の文字は変わらない (案Aの場合)
- [ ] 完了したタスクが記録に残り、期限内か遅れたかが分かる
- [x] 保存データを壊した状態で開いても、元のデータが退避されて残る
- [ ] 2つのタブで開いて、片方で追加したタスクがもう片方に出る
- [ ] マウスを使わず、キーボードだけで追加、完了、削除ができる
- [ ] スマートフォン幅で、全ての操作ができる (`mobile.md`)
