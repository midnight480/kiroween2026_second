# 名簿 (チームメンバー)

チームメンバーの一覧、役割、最終アクセス時刻を扱う画面の仕様です。画面は `members.html` (`src/members.ts`) です。

## 前提

- **名簿はプロジェクトごと** (2026-11-19 に全プロジェクト共通から変更)。メンバーはプロジェクトの中で作られ、そのプロジェクトのタスクだけを担当できる。
- 名簿はプロジェクトの一部 (`Project.members`) として保存する。ゲストは `localStorage`、サインインした人はサーバー (Neon) で、プロジェクトと一緒に同期される (`deploy.md`)。
- 最終アクセス時刻 (Last seen) は、この端末で「This is me (これが自分)」の印を付けた人だけを記録します。印はプロジェクトごとに付けます。サインインしていれば記録はプロジェクトと一緒に同期されるので、ほかの端末からも見えます。
- 役割は記録と表示だけで、操作の制限はしません。下の「役割」の権限は、共有 (他人を招待する仕組み) を入れるときに実装します。
- サインインしたアカウントと名簿のメンバーは、まだ結びつけていません。

## データ

```ts
type Role = "owner" | "admin" | "member" | "viewer";
interface Project {
  // …(projects.md)
  members: Member[]; // このプロジェクトの名簿。100人まで
}
interface Member {
  id: string;        // crypto.randomUUID()。タスクの assignee はこの id (同じプロジェクトの名簿の中で探す)
  name: string;      // 1〜30文字。同じプロジェクトの名簿の中で重複しない
  role: Role;        // 初期値 member
  created: number;   // ms
  lastSeen?: number; // ms。「自分」の印を付けた人だけ記録される
}
```

- この端末の「自分」: `tomoshibi.me.v2` (`{ [projectId]: memberId }`)。
- **移行**: `members` を持たないプロジェクトを読み込むと、旧来の共通の名簿 (`tomoshibi.members`) を同じ id のまま写す。タスクの担当者はそのまま残る。旧来の「自分」(`tomoshibi.me`) は、その id がいるプロジェクトで「自分」とみなす。旧来のキーは消さない。
- 新しいプロジェクトの名簿は空から始まる。登録画面の「+ 担当者を追加…」か名簿のページで足す。
- タスクを別のプロジェクトへ移すと、移した先の名簿にいない担当者は外れる (登録画面で担当者の選択肢が切り替わる)。
- 最終アクセスの記録 (`touchMe()`): 看板と名簿のページで、開いたとき、タブに戻ったとき、タスクを保存したときに、開いているプロジェクトの「自分」を記録する。書き込みは1分に1回まで。ヘルプなど、プロジェクトを読み込まないページでは記録しない。
- 名簿の変更はプロジェクトの保存として扱う。ゲストなら `storage` イベントで看板に届き、サインイン中なら看板がサーバーを読み直したとき (タブに戻ったときと1分ごと) に届く。

## 画面

| 項目 | 決まり |
|---|---|
| プロジェクト | 一番上で選ぶ (2つ以上あるとき)。選んだものは看板でも開くプロジェクトになる |
| 一覧の列 | 名前 (頭文字の印)、役割、担当の灯 (未完了の数と、そのうち期限切れの数)、最後に見た時、操作 |
| 並び順 | 役割 (Owner → Viewer)、同じ役割の中は名前順 |
| 追加 | 上の行で名前と役割を入れて「Add to the household」。名前が空か重複なら、塩が崩れてメッセージ |
| 名前の変更 | 名前の欄をそのまま書き換え、Enter か欄の外で確定。Esc で取り消し |
| 役割の変更 | 行の選択肢で変える。すぐ保存 |
| 自分の印 | 「This is me」。押した人の行に「you」と左の灯の線が付き、その時刻を最後に見た時として記録する |
| 外す | 「Remove」を0.9秒長押し。担当していたタスクは消さず、担当者なしになる。「自分」だった場合は印も外す |
| 最後に見た時 | 「5 min ago」の形 (`Intl.RelativeTimeFormat`)。マウスを乗せると日時。30秒ごとに更新 |
| 姿を見ない人 | 7日以上見ていない人の行は薄くなり、「Not seen for n days」を添える。マウスを乗せるかフォーカスすると元の濃さに戻る (読めることを優先) |
| 狭い画面 | 表を行ごとのカードに組み替える |

## 役割 (権限は予定)

| 役割 | できること (サインイン後) |
|---|---|
| Owner | 全て。名簿と役割の変更も。最低1人は必要 |
| Admin | 全てのタスクの操作と、メンバーの追加・削除 |
| Member | タスクの追加、編集、完了 |
| Viewer | 見るだけ |

- 「最低1人の Owner」は、権限を実装するときに入れる。いまは制限しない。

## ショートカット

| キー | 名簿のページで |
|---|---|
| `N` | 名前の欄へ |
| `B` か `Esc` | 看板に戻る |
| `?` | ヘルプ |

看板とヘルプでは `T` で名簿を開く。

## 対象外 (いまは入れない)

- 招待、メール、ほかの端末との同期 (サインインとサーバーが要る)。
- ガントチャート (ユーザーの判断で見送り。`roadmap.md` の候補)。
