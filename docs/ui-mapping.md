# 和ホラー要素とUI機能の対応

「怖さがあるから操作が分かりやすい・楽しい」を満たす対応表です。表はタスク管理の機能を軸にしています。新しい演出は、この表に行を足してから実装します。

- 機能の一覧と優先度は `features.md`、各要素の日本での意味と英語での伝え方は `japanese-horror.md` にあります。
- 「Safe mode」列は、Safe mode のときの振る舞いです。閃光、人影、女の登場、大音量は必ず無効にします。

状態: ✅ 実装済み / ⬜ 未実装

## 実装済み

| 期限切れの通知 | 怨霊 | 暗転、血が上から流れる、女が現れて近づき飛びかかる、「遅かったね」 | 見逃しようのない通知。1タスク1回だけ | 暗転と血のあと、女と閃光を飛ばして文字だけ | `curse.ts` |

| 完了 | 御札の封 | 封を0.9秒長押しで剥がす。蝋燭が消えて退場 | 確認ダイアログの代わり。誤って完了しない | 同じ | `main.ts` `wireSeal()` |
| 期限切れの片付け | お祓い | 呪われたカードは「Hold to exorcise」。いまは削除と同じ。仕様では「遅れて完了」にし、記録に残す (`task-management.md`) | 期限切れと通常のタスクで、操作の意味の違いが分かる | 同じ | `main.ts` `refresh()` |

| 主要操作の誘導 | ジャック・オー・ランタン | 追加ボタン。入力があると光る | 押せる状態になったことが分かる | 同じ | `main.ts` `PUMPKIN` |

| テーマ切替 | 逢魔が時・丑三つ時 | 17〜18時と夜間に暗さと色味が変わる。2時台は気配が増える | 時刻が画面から分かる | 同じ | `main.ts` `applyTheme()` |
| ルールの提示 | 見るなのタブー | 画面端の人影に近づくと消え、ランダムな蝋燭が10%短く見える。フッターに掟 | 「見るな」というルールを、説明文なしで体で覚えられる | 人影を出さない (囁きだけ) | `presence.ts` `figure()` |

| テーマ (ライト) | 障子・白昼の怪 (未実装) | 障子越しの光。カーソルの周りに影。気配は障子に映る影絵 | 明るい環境でも読みやすく、それでいて不穏 | 影絵の人影は出さない | (未実装) |

| テーマ (ライト) | 障子・白昼の怪 | 障子の格子の地。カーソルの斜め後ろに影が落ちる。人影はぼかした影絵、目は黒 | 明るい環境でも読みやすく、それでいて不穏 | 人影は出さない。影は薄くなる | `style.css` `:root[data-theme="light"]` |
| 多言語 | 言葉の異物感 | 英語版でも和ホラーの語 (灯、遅、うしろ、数え歌) だけ日本語で残す | 言語を変えても、作品の空気が同じに保たれる | 同じ | `i18n.ts` |
