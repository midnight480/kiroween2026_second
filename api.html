灯The ledger API帳面の API

Light and read candles from scripts, CI, chat bots or anything that can send HTTP. The API works on the ledger of a signed-in account: the same tasks you see on the board after signing in.

スクリプト、CI、チャットボットなど、HTTP を送れるものから灯を登録・取得できます。API が扱うのは、サインインしたアカウントの帳面です。サインイン後に看板で見えるタスクと同じものです。

Get a keyキーを発行する

  1. Sign in (top right of any page).
  2. Open your account: press your avatar, then Manage account.
  3. Open API keys, press Add new key, and give it a name (for example ci-bot).
  4. Copy the key right away. It is shown only once. Keep it like a password: never put it in a public repository or in web page code.
  1. サインインします (どのページでも右上)。
  2. アバターを押し、アカウントを管理を開きます。
  3. API キーを開いて新しいキーを追加を押し、名前を付けます (例: ci-bot)。
  4. キーはその場でコピーしてください。表示されるのは1度だけです。パスワードと同じように扱い、公開リポジトリや Web ページのコードには入れないでください。

A key can be revoked on the same page at any time. A revoked key stops working within a minute.

キーは同じページでいつでも取り消せます。取り消したキーは、1分以内に使えなくなります。

Sending the keyキーの送り方

Send the key in the Authorization header of every request. Bodies are JSON.

すべてのリクエストで、キーを Authorization ヘッダーに入れて送ります。本文は JSON です。

Authorization: Bearer <your key>
Content-Type: application/json

Base URL: https://tomoshibi.midnight480.com/api/v1

Examples例

Put your key in an environment variable first, so it does not end up in your shell history.

キーは先に環境変数に入れておきます。シェルの履歴にキーを残さないためです。

export TOMOSHIBI_KEY="..."   # paste the key here
API=https://tomoshibi.midnight480.com/api/v1

# projects and their rosters
curl -s "$API/projects" -H "Authorization: Bearer $TOMOSHIBI_KEY"

# light a candle that burns for two hours
curl -s -X POST "$API/tasks" \
  -H "Authorization: Bearer $TOMOSHIBI_KEY" -H "Content-Type: application/json" \
  -d '{"title": "Review the release notes", "minutes": 120}'

# a fixed deadline, in a given project, for a given member
curl -s -X POST "$API/tasks" \
  -H "Authorization: Bearer $TOMOSHIBI_KEY" -H "Content-Type: application/json" \
  -d '{"title": "Send the invoice", "due": "2026-11-20T18:00:00+09:00",
       "project": "PROJECT_ID", "assignee": "MEMBER_ID", "note": "PDF from the shared drive"}'

# open candles in one project
curl -s "$API/tasks?project=PROJECT_ID&status=todo" -H "Authorization: Bearer $TOMOSHIBI_KEY"

# put it out (finish)
curl -s -X PATCH "$API/tasks/TASK_ID" \
  -H "Authorization: Bearer $TOMOSHIBI_KEY" -H "Content-Type: application/json" \
  -d '{"status": "done"}'

The task objectタスクの形

{
  "task": {
    "id": "5b0c…",
    "project": "a1f2…",
    "title": "Review the release notes",
    "note": null,
    "assignee": null,
    "status": "todo",
    "due": "2026-11-19T11:00:00.000Z",
    "created": "2026-11-19T09:00:12.345Z",
    "doneAt": null,
    "late": false,
    "overdue": false,
    "extended": 0
  }
}
  • Times come back in UTC (Z). overdue is true while the task is open and past its deadline.
  • late is true for a task finished after its deadline. extended counts how many times the deadline was moved later.
  • A candle lit through the API appears on an open board within a minute, and at once on the next visit.
  • 時刻は UTC (Z) で返ります。overdue は、未完了で期限を過ぎているとき true です。
  • late は期限後に完了したとき true です。extended は期限を後ろへ延ばした回数です。
  • API でともした灯は、開いている看板には1分以内に、次に開いたときはすぐに出ます。

Errors and limitsエラーと上限

Errors come back as {"error": "…"} with the reason in plain words.

エラーは {"error": "…"} の形で、理由を英文で返します。

StatusMeaning
ステータス意味
400Something in the body is missing or not allowed (the message says which).
400本文の項目が足りないか、決まりに合わない (どれかはメッセージに出ます)。
401No key, or the key is unknown, revoked or expired.
401キーがない。または、知らないキー、取り消したキー、期限切れのキー。
404No such task or project in your ledger.
404あなたの帳面に、そのタスクかプロジェクトがない。
409The project already holds 60 open candles, or you have no project yet (sign in on the board once).
409そのプロジェクトの未完了がすでに60件ある。または、まだプロジェクトがない (一度サインインして看板を開いてください)。
413The body is larger than 16 KB.
413本文が 16 KB を超えている。
429More than 60 requests in a minute with one key. Wait the seconds in Retry-After.
4291つのキーで1分に60回を超えた。Retry-After の秒数だけ待ってください。
  • The API can only reach your own ledger. Guests (not signed in) keep their candles in the browser, where the API cannot see them.
  • Burning (deleting) a task is not available through the API on purpose. Do it on the board.
  • Calls from a web page on another site are not allowed (no CORS). Call the API from a server or a script.
  • API が触れるのは、自分の帳面だけです。サインインしていない場合、灯はブラウザの中にあり、API からは見えません。
  • タスクを燃やす (削除する) 操作は、あえて API に入れていません。看板で行ってください。
  • ほかのサイトの Web ページからは呼べません (CORS なし)。サーバーやスクリプトから呼んでください。
